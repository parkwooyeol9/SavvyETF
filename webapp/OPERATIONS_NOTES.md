# 운영 노트
교육 메뉴 가장 오른쪽의 관리자 전용 개인 보관함. 기존 상단 관리자 로그인을 재사용하며 일반 회원 로그인으로는 접근할 수 없습니다.

## 배포
기존 R2 환경변수 외에 Vercel의 해당 배포 환경에 `OPERATIONS_NOTES_ENCRYPTION_KEY`를 설정하고 재배포합니다.
`openssl rand -hex 32`로 생성한 64자리 hex 값을 사용합니다. NEXT_PUBLIC_ 접두사는 사용하지 않습니다.
키를 안전하게 별도 백업하세요. 키 분실 또는 데이터 이관 없는 키 변경 시 기존 노트 복호화가 불가능합니다.
설정이 없으면 API는 503을 반환하고 저장하지 않습니다. 운영 R2 자격증명을 신뢰하지 않는 Preview 환경에 공유하지 마세요.

## 기능 및 제한
- 제목, 분류, 텍스트 본문(50,000자), 검색, 수정, 삭제
- 첨부 최대 10개, 게시글당 합계 3 MiB (Vercel 요청/응답 크기 제한 고려)
- PNG/JPEG/WebP/GIF 인증 후 미리보기, PDF/Excel/CSV 등 원본 다운로드
- HTML/Markdown 실행 또는 렌더링 없음
- 첨부 포함 노트 전체를 AES-256-GCM으로 암호화하여 R2 `private-operations-notes/{uuid}.bin` 저장
- 무작위 IV, 객체 경로 AAD 사용. 제목/본문/파일명/첨부 모두 암호화
- 모든 API 메서드 및 다운로드에 관리자 인증, private/no-store 응답
- 기존 공개 R2에서도 객체 내용은 암호문. 크기/수정시각 등 저장소 메타데이터는 숨기지 않음
- 목록은 전체 노트를 조회. 대규모 아카이브에는 페이지 처리/검색 색인 확장 필요
- 같은 노트를 동시에 수정하면 마지막 저장이 반영됨

## 검증
`node scripts/test-operations-notes.cjs`, `npx tsc --noEmit`, `npm run check:imports`.
배포 후 관리자 로그인 → 교육 → 운영 노트 → 이미지/CSV 업로드 → 새로고침 → 조회/다운로드 확인.
로그아웃 후 탭/데이터가 사라지고 인증 헤더 없는 API/첨부 요청은 401이어야 합니다.
실제 R2 연결 및 브라우저 동작은 배포 환경에서 추가 확인해야 합니다.
