# 보존 정책

R2 무료 용량(~10GB)으로 모니터 일별 JSON은 충분합니다. 수백 KB/일 규모면 연간 수백 MB.

| 세트 | 핫 | 아카이브 | 삭제 |
|---|---|---|---|
| [[한국 상장 ETF]] | `etf_db/snapshots/` 90일 | `etf_db/archive/` | 복사 성공 전에는 핫에서도 안 지움 |
| [[미국 상장 ETF]] | `etf_db_us/snapshots/` 전량 | 별도 prefix 없음 (스냅샷이 곧 보존) | 자동 삭제 없음 |
| [[종목 뉴스 감성]] | 종목 JSON: 점수 전 기간 + 최근 30일 제목 | `nlp_history/headlines/{code}/{YYYY-MM}.json` | 아카이브 실패 시 제목 압축 안 함 |
| [[시황 브리프]] | 슬롯 latest + history 5버전 | `briefs/{tab}/archive/{slot}/` | history에서만 제거 |
| 모니터 | `latest.json` + `snapshots/{날짜}.json` | 스냅샷이 곧 보존 | prune 없음 |

모니터: [[글로벌 자금 흐름]] · [[CFTC 포지션]] · [[신용 자금]] · [[코스닥100]] · [[ESG 이벤트]] · [[미 중간선거]]

수동 아카이브: 저장소 루트에서 `python data_archive.py` (R2 키 필요).
