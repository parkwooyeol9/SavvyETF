# 시세 뉴스 API

저장소가 아니라 **밖에서 숫자를 가져오는 곳**. 일부는 R2에 남고, 일부는 그때 보고 버린다.

그림: [[시세 뉴스 API 지도]]

| 소스 | 가져오는 것 | 화면 | 적재 |
|---|---|---|---|
| Yahoo | 일봉·종가·환율 | 차트·히트맵·NLP 주가선 | 차트는 일회. 미국 ETF·자금흐름 스냅샷에 일부 |
| 네이버 | 뉴스 제목, ETF AUM, 호가 | NLP, 한국 ETF DB | 제목+점수 `nlp_history/`. AUM `etf_db/`. 호가는 버림 |
| FRED | 금리·스프레드 | 매크로·자금흐름 | 키 필요. 스냅샷에 일부 |
| Finnhub | 프리장·캘린더 | `/summary_pre`, NLP | 키 필요. 대부분 일회 |
| DART | 공시·재무 | NLP 분홍 점, `/dart` | 키 필요. 원문은 일회 |
| 업비트 | KRW 시세, 주문 | 크립토·김프 | 시세 일회. 챌린지 상태 R2 |
| 바이낸스 | 선물 OI·펀딩, 주문 | 자금흐름·김프 | 시세 일회. 페이퍼 상태 R2 |
