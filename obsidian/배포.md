# 배포 (git 요약)

- Vercel `savvyetf`, Root `webapp`, `main` 푸시 → Production
- **Error 빌드는 Production을 덮지 않음** (직전 Ready 유지)

## import 체크

```bash
cd webapp
npm run check:imports
npm run build   # prebuild에서도 동일
```

CI: `.github/workflows/webapp-import-check.yml`

실패 패턴: 로컬에만 있는 컴포넌트를 import한 채 부분 커밋 → Vercel `Module not found`.
