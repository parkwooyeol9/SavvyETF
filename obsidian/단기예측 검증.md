## 한 줄 결론

BTC 5m(~18일) walk-forward+holdout에서 **historical 분위수가 CRPS 1위**. LightGBM은 EWMA만 소폭 상회, **비용 차감 후 기대수익 음수**. DL/Kronos **추가하지 않음**.

## ①–⑦

상세 표·Mermaid·실험표는 보관함 노트 **단기예측 검증**을 연다.

| 섹션 | 요지 |
|---|---|
| ① 구조 | OKX perp / GLD ETF / CL=F → QC → 1h·4h 라벨 → WF → TS 선형분위수 vs Python 기준모델 |
| ② 문제 | 롤오버·표본부족·구 holdout·미완성봉; scaler는 train-only |
| ③ 유지/수정 | WF·CRPS 유지; instrument·confirm·세션라벨·holdout·연구하네스 추가 |
| ④ 우선 | ≥90일 아카이브, hist/EWMA prior, LGBM research-only |
| ⑤ 실험표 | B0–B3, M1–M2 실행 / M3–M5 보류 |
| ⑥ 코드계획 | research 하네스 + minuteForecast.ts P0 완료 |
| ⑦ 결과 | holdout CRPS: hist 0.002055 < lgbm 0.002104 < ewma 0.002196; linear 실패 |
