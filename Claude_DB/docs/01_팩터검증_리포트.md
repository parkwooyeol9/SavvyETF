## 2. 수정 모델 (v2)

1. **정제**: ACWI 비중 0(러시아·편출·선물), 섹터 없음 14종목(현금성 펀드 1, TR 조회 실패 13) → 27종목 제외, 2,239종목 분석.
2. **USD 유동시총**: ACWI 비중 × (미국 상장 종목 MV÷비중 중앙값 = 103.4조$). ln 변환 후 사이즈.
3. **통화 정합**: 보고통화 후보(영국 GBP·USD·EUR, 북유럽 EUR·USD, 중남미·인니·필리핀 USD, 중국 ADR CNY 등)마다 보정계수 k 를 구해
   - Datastream FCF 수익률(통화 일관)과 E/P 가 6배 이상 가까워지면 적용(ROE≥3% 종목) — 35종목
   - 앵커가 없으면 P/E·P/B 가 섹터×지역 중앙값에 4배 이상 가까워질 때 적용 — 30종목
   - 홍콩·대만·한국·일본 등 자국통화 고PER 종목이 많은 시장은 앵커가 있을 때만
   - 후보 통화 간 차이(예: 셸 USD vs GBP)는 ±30% 정도 남을 수 있음 → 근본 해결은 `~U$` 요청
4. **디스크립터**: E/P·B/P(수익률 형태), 변동성 = SD÷주가, 12-1M 복리, 성장률은 적자·흑전·적전 제외, D/E 는 금융 제외·음수 제외.
5. **윈저라이징**: 디스크립터별 전체 1%/99%.
6. **섹터×지역 중립 Z**: 같은 섹터·지역 표본의 평균·표준편차(같은 윈저 표본), ±3 절단. 그룹 표본<10 이면 섹터, 섹터<5 면 전체.
7. **팩터**: 디스크립터 Z 평균 → 그룹 내 재표준화(분산 1) → 결측은 0.
8. **종합**: 가중합 ÷ 가중치합 → 전체 Z → 순위·백분위·섹터내 순위.

엑셀 v2(`FACTOR_v2`)는 같은 계산을 엑셀 수식으로 구현했고, LibreOffice 재계산 결과가 파이썬과 2,239종목 모두 순위 일치(최대 차이 8e-6)합니다. 통화보정계수는 `MAP_v2` J:N 열에 있어 직접 고칠 수 있습니다.

## 5. 2026-10-02 파일(~U$) 재작업

- Datastream 요청이 `X(MV)~U$`, `X(EPS1FD12)~U$`, `X(BPS1FD12)~U$`, `X(DPS1FD12)~U$`, `X(INC1FD12)~U$`, `X(SAL1FD12)~U$` 로 바뀜. 엔진이 3행 헤더로 자동 판별.
- **보고통화 추정 보정 불필요**: 지난 추정(65종목)과 비교하면 실제로는 15% 이상 어긋난 종목이 260개였음 (AIA PER 91→11.7배, 텐센트·노바티스·BHP 등). ~U$ 가 정확한 방법.
- **남은 문제: 현재가 X 는 현지통화.** 엑셀 AA·AB(P/E·P/B)는 해외 종목에서 USD EPS 를 현지 주가로 나눠 수십~수천 배가 되고 PER 300배 컷에 걸려 가치 점수가 1,577종목만 계산됨. v2 는 2026-10-01 환율과 호가단위로 USD 환산. 영국은 대부분 펜스, 남아공·이스라엘은 실제로 랜드·셰켈 단위. 예외 3종목(Compass·IHG = GBP 단위로 판별, Verisure = EUR 호가). IHG 는 단위가 불확실 → `X~U$` 추가 시 해결.
- **사이즈 정의 변경**: ACWI 비중 기반 유동시총 → `MV~U$` 전체 시가총액. 중국 A주처럼 MSCI 편입비율이 낮은 대형은행이 '소형주'로 잡히던 문제 해소 (공상은행·중국은행 순위 하락의 주원인).
- 엑셀 W·X(배당수익률·모멘텀) 수식은 이번 파일도 19행에만 있음. BE~BO 는 전 행 채워짐.
- 결과: 수정 모델 순위는 지난 결과와 순위상관 0.92, 상위 100 중 73종목 유지. 엑셀(AJ) 순위와의 상관은 0.37.
- v2 엑셀은 LibreOffice 재계산 기준 파이썬과 2,239종목 순위 완전 일치.
