### 2-2. 로직 검토 포인트 (의견 달고, 바꾸면 docs/03 에 기록)
1. **국가 상대 모멘텀** (`engine.descriptors`): 국가 중앙값 대비 복리 초과. 국가 종목 1개면 지역 중앙값. 이집트(2종목)처럼 표본이 작으면 노이즈 큼 — 임계값 2가 적절한지
2. **급변 규칙**: 최근 10거래일 ±40% → 밸류·배당 디스크립터 비움 (CTVA 10-01 −84%, 스핀오프 미조정 의심). 데이터가 정정되면 자동 해제되는지
3. **근사 PER 밴드** (`fundamentals_ts.compute`): `P_t/P_now = RI_t/RI_now × (1+현재배당수익률)^경과연수`. 가격(현지통화)과 추정치(보고통화)가 다르면 환율 오차. 3년 최저(백분위 0)가 281종목 — 최근 하락+리비전 상향으로 설명되지만 표본 몇 개(NVDA·AMZN·HD)를 Datastream PE 시계열과 대조해 볼 것
4. **베타**: 벤치마크 = 파일 종목 ACWI 비중 × **현지통화** 수익률. 공식 ACWI 베타와 다름 (미국 중앙값 0.82)
5. **이벤트 스터디** (`index_link.event_study`): t0 = 발표 다음 거래일, 시장조정(종목−벤치마크) 단순합. 편입은 **생존 편향**(이후에도 남은 종목만), 편출은 May26·Aug26만. 현지통화
6. **편출 관찰 리스트**: 국가 내 **회사 단위**(주식 클래스 합산, 이름 정규화) 누적비중 꼬리. 검증이 표본 내(같은 파일 비중)라 낙관적일 수 있음. MSCI 실제 기준(유동시총 하한·버퍼·EM/DM 컷오프)과 다름 → 화면 문구에 "참고"
7. **이름 매칭** (`msci_pit.norm_name`): 하이픈 규칙 변경 후 `acwi_unmatched.csv` 건수 640/43/15 로 이전과 동일, EFG-HERMES ↔ EFG Holding 이 새로 맞음. 동점 후보가 둘 이상이면 첫 번째가 선택되는 구조 → `best_match` 에 동점 플래그 추가 고려
8. **성능**: `msci_pit.reconstruct` 가 O(리뷰×행×앵커)로 약 2.5분. 웹 배포와 무관하지만 갱신 주기에 영향
9. **원자료 열 이름 의존**: `engine.detect_columns` 헤더 정규식. Datastream 요청식이 바뀌면 `intake` 리포트 1장(필드↔헤더 매핑)부터 확인

## 3. 웹앱 배포 설계 (Cursor 2단계)

### 3-1. 현재 웹앱 구조 중 관련 부분 (확인 완료)
- 탭 정의: `webapp/src/lib/types.ts` — `TabId` 유니언, `TAB_LABELS`, `NAV_GROUPS`(ETF > 리밸런싱 묶음 `tabs: ["rebalance", "indexmonitor"]`), `ADMIN_ONLY_TABS`, `parseShellTab` 별칭
- 탭 렌더: `webapp/src/components/Dashboard.tsx` 의 `tab === "indexmonitor" ? <IndexMonitorTab />` 체인, 관리자 전용은 `unlocked ? <X/> : null`
- 지연 로딩: `webapp/src/components/lazyTabs.tsx` (`dynamic(() => import(...))`)
- 관리자 인증: 클라이언트 `useAdminSession()` (`components/AdminSession.tsx`) + `adminAuthHeaders(secret)` (`lib/adminSession.ts`) → 서버 `requireSiteAdmin(request)` / `PRIVATE_NO_STORE` (`lib/adminGuard.ts`). **UI 숨김은 접근 제어가 아님 — API 에서 반드시 `requireSiteAdmin`**
- 참고 구현: `app/api/index-monitor/route.ts` (MSCI 행 관리자 분기, `?scope=admin` 은 캐시 분리), `app/api/admin-vault/route.ts` (requireSiteAdmin + R2)
- R2: TS `lib/r2.ts` (`r2GetObjectText`, `r2PutObject`), Python `r2_data.py` (`put_json`, `put_json_daily`, `get_json`; `r2_briefs.py` 의 R2_* 환경변수 공유)
- 차트 라이브러리: `recharts` 이미 의존성에 있음
- 배포 전 검사: `npm run check:imports` (prebuild 자동), `npm run build`, GitHub Actions `webapp-import-check.yml`

### 3-2. 목표 구조
```
[맥] Datastream 엑셀 갱신
   └─ python -m Claude_DB.factor.analyzer --xlsx ... --as-of ...
   └─ python -m Claude_DB.factor.export_webapp --upload         ← 신규 (3-3)
          R2(비공개): acwi_analyzer/latest/summary.json          ~2MB (series 제외 전부)
                      acwi_analyzer/latest/series/{bucket}.json  종목 시계열을 코드 해시로 32~64개 묶음
                      acwi_analyzer/snapshots/{YYYY-MM-DD}/...   (같은 구조, 이력)
[Vercel] /api/acwi-analyzer?part=summary          → requireSiteAdmin → R2 summary
         /api/acwi-analyzer?part=series&code=XXX  → requireSiteAdmin → R2 해당 bucket → 그 종목만 반환
         헤더: PRIVATE_NO_STORE (CDN 캐시 금지). 람다 메모리 캐시는 asOf 키로 짧게(5분) OK
[브라우저] ETF > 리밸런싱 > "ACWI 분석" 탭 (ADMIN_ONLY) — AcwiAnalyzerTab.tsx
```
분할 이유: 6.8MB 를 한 번에 받으면 첫 화면이 느리고 Vercel 응답 크기 한도(4.5MB)에 걸릴 수 있음. 표·브레드스·이벤트는 summary 로, 차트용 주간 RI·월간 EPS/BPS/DPS/PE 는 종목 클릭 시 받기.

### 3-3. 신규 파일 — 해야 할 일과 완료 기준

**(1) `Claude_DB/factor/export_webapp.py`** (Python)
- 입력: `analyzer.build()` 가 만든 dict (현재는 JS 로만 씀) → `analyzer.py` 에 `web` dict 를 `out/analyzer/web_payload.json` 으로도 저장하게 한 줄 추가하고 그걸 읽는 게 가장 단순
- 출력: summary.json (`meta, quality, stocks, breadth, events, pending, reviews`) / series 묶음 (`weeks, months, bench` 는 summary 에, 종목별 `ri, eps, bps, dps, pe` 는 bucket 파일)
- `--upload`: 저장소 루트 `r2_data.put_json` 재사용 (Cache-Control 은 `private, no-store` 로 — 지금 `put_bytes` 기본값 확인 필요). `--dry-run` 은 로컬 `out/webapp_export/` 에만
- 완료 기준: summary < 3MB(gzip 전), 버킷 파일 각 < 500KB, 업로드 후 `get_json` 으로 asOf 확인

**(2) `webapp/src/lib/acwiAnalyzer.ts`** — 타입 + 키 상수
- 레코드 키는 `analyzer.py` 의 `KEYS` 딕셔너리가 원본 (짧은 키 c, n, ct, rg, s, ind, w, cap, pe … 주석과 함께 그대로 옮길 것)
- `AcwiAnalyzerSummary`, `AcwiStock`, `AcwiSeries`, `bucketOf(code)` (Python 과 같은 해시 — 예: `sum(ord(ch)) % N` 처럼 단순·결정적으로, 양쪽 테스트 추가)

**(3) `webapp/src/app/api/acwi-analyzer/route.ts`**
- `export const runtime = "nodejs"; export const dynamic = "force-dynamic";`
- 첫 줄 `const denied = requireSiteAdmin(request); if (denied) return denied;`
- R2 미설정·객체 없음 → 503 `{ok:false, error}` (admin-vault 패턴)
- 모든 응답 `PRIVATE_NO_STORE`
- 완료 기준: 비로그인 `curl` → 401, 관리자 토큰 → 200, 응답 헤더 `cache-control: private, no-store`

**(4) `webapp/src/components/AcwiAnalyzerTab.tsx`** — `web/analyzer.html` 을 React 로 이식
- 하위 보기 5개: 시장 개요 / 스크리너 / 종목 상세 / MSCI 편출입 / 데이터·방법 (IndexMonitorTab 의 `View` 패턴)
