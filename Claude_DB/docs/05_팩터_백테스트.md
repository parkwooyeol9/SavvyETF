## 2. 백테스트 방법

- **기간**: 2017-10 ~ 2026-09 신호, 108개월 (12-1M 모멘텀·24M 변동성 준비 기간 제외). 매월 1일(Datastream 월간 날짜) 리밸런싱
- **수익률**: 다음 달 1일까지 현지통화 총수익(RI). 5분위 동일가중, 롱숏 = Q1 − Q5, 벤치마크 = 유니버스 동일가중(시총가중 병기)
- **신호** (현재 모델과 같은 6팩터 구조, 과거 시계열이 없는 FCF·D/E 는 제외)

| 팩터 | 디스크립터 |
|---|---|
| 가치 | E/P, B/P |
| 사이즈 | −ln 시총 (시총_t = 시총_now × 주가 상대값, 주식 수 불변 가정) |
| 배당 | 배당수익률, DPS NTM 12M 변화 |
| 성장 | EPS NTM 12M 변화, 매출 NTM 12M 변화 |
| 모멘텀 | 12-1M 총수익(국가 중앙값 대비), EPS 3M 리비전(ΔEPS/주가) |
| 퀄리티 | ROE(=EPS/BPS, NTM), −변동성(월간 24M) |

  매월 1/99% 윈저 → 섹터×지역 중립 Z(±3) → 디스크립터 평균 → 다시 중립 Z. 조합: 종합(6팩터 동일) · 종합(사이즈 제외) · 가치+모멘텀 · 퀄리티+모멘텀 · 가치+퀄리티
- **과거 주가 수준 복원** (`price_relative`): RI 는 배당 재투자라 주가와 다름 → `P_t = P_{t+1} × RI_t/RI_{t+1} × (1 + 배당수익률/12)` 로 거꾸로 쌓음. **검증: 복원한 12M 주가변화가 파일의 `PCH#(X,12M)` 와 2,187종목 중 94%가 ±2%p 이내(상관 0.9998)**. RI 를 그대로 쓰면 46%. 과거 E/P = EPS_t × (USD 추정치_now ÷ 보고통화 추정치_now) ÷ (USD주가_now × P_t) — 마지막 달 E/P 가 스냅샷과 100% 일치
- **유니버스 (look-ahead 처리)**

| 모드 | 정의 | 의미 |
|---|---|---|
| `pit` (기본) | 그 달 ACWI 구성이었던 종목만 (`index_monitor` 편입·편출 구간, ISIN 매칭) | 편입 전·편출 후 제외 → 편입 look-ahead 제거 |
| `pit_large` | pit 중 그 달 지역별 시총 상위 50% | 편출 종목 누락은 주로 소형주 → 생존 편향이 덜한 비교군 |
| `static` | 지금 파일 종목 전부 | 비교용 (look-ahead 포함) |

  커버리지(파일 종목 중 PIT 구성 ÷ 재구성 실제 구성종목): 2017-10 55% → 2020-10 61% → 2023-10 71% → 2025-10 93%. **2026-02 이전 편출 종목은 파일에 없어 세 모드 모두 생존 편향이 남음**

해석
1. **사이즈 팩터는 생존 편향의 산물**: 현재 구성 고정 22.6% → PIT 12.7% → 대형·중형 2.3%. '지금 ACWI 에 있는 과거 소형주' = 나중에 커서 살아남은 종목이라 미래 수익이 높게 찍힘. 사이즈가 들어간 종합 점수도 같은 이유로 부풀려짐 → **실전 판단은 '종합(사이즈 제외)'·'PIT 대형·중형' 기준 권장**
2. **모멘텀이 가장 견고**: 대형·중형에서도 롱숏 7.7%, IC t 2.4, 1개월 지연해도 8.1%. EPS 3M 리비전 디스크립터 단독으로도 롱숏 7.3%(편도 20bp 비용 후 4.5%)·IC t 2.8
3. **퀄리티는 음(−)**: 저변동성·ROE 가 2017~2026 성장주·고베타 장세에서 역행. 현재 퀄리티 정의(ROE·D/E·변동성) 재검토 후보
4. 지역별(PIT 종합): 미국 1.0% · 선진(미국 외) 5.5% · 신흥 13.5% — 팩터 효과가 신흥국에서 크고 미국에서 약함 (현지통화·생존 편향 영향 포함)
5. **1개월 지연(`--lag 1`)**: PIT 종합 7.8 → 5.8%, 모멘텀 5.7 → 5.1%, 대형·중형 종합 6.6 → 6.7% — 결과가 시점 정렬에 크게 의존하지 않음

## 4. 한계와 다음 단계

- **생존 편향**: 가장 큰 한계. 해결하려면 과거 시점 ACWI 구성종목(편출 종목 포함)의 월간 RI·EPS 가 필요 → Datastream 에서 `acwi_name_map_todo.csv`(편출 종목 이름) ISIN 매핑 후 그 종목들의 시계열을 추가로 받으면 PIT 커버리지 100% 근처로 올릴 수 있음
- 현지통화 수익률 (USD 기준 필요 시 `X(RI)~U$` 월간 10년)
- 섹터는 현재 GICS 분류를 과거에 적용, 시총은 주식 수 불변 가정
- 거래비용은 회전율 기반 근사 (Q1 = 2×회전율×비용, 롱숏 = 4×회전율×비용), 유동성 제약 없음
