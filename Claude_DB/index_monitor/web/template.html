    국내 수급 관점의 핵심 차이

    • MSCI Korea는 전체 시총과 유동 시총 두 기준을 모두 넘어야 편입됩니다. 가격 기준일이 직전 월말 10영업일 중 임의일이라 사전 예측에 불확실성이 큽니다.
    • 코스피200은 산업군별 누적 시총과 유동성으로 뽑고 기존 종목에 버퍼를 줍니다. 대형 신규상장은 특례로 수시 편입됩니다.
    • FTSE는 한국을 선진시장으로, MSCI는 신흥시장으로 분류합니다. MSCI는 2026년 6월 리뷰에서도 관찰대상국 등재를 보류했습니다.
    • Nasdaq-100은 2026년 5월부터 3·6·9월에도 순위 심사로 종목을 교체하고, 초대형 신규상장은 15거래일 만에 편입합니다.

    과거 리밸런싱 이력, 적재할 수 있나

    가능합니다. 다만 소스마다 형식과 권리가 달라 한 가지 방법으로는 안 됩니다. 공지(이벤트) 이력은 무료 공개 자료로 대부분 모을 수 있고, 시점별 구성종목·비중은 Datastream이나 ETF 보유종목 스냅샷으로 채우는 구조가 현실적입니다.

    실제 검증: MSCI 2026년 8월 공개 리스트를 파서로 읽어 23개국 147행을 만들었고, 국가별 편입·편출 수가 MSCI 요약표와 모두 일치했습니다(합계 편입 55 · 편출 92 = 보도자료 ACWI 수치). 이 페이지의 데이터 263행은 같은 스키마로 SQLite에 적재한 결과입니다.
    소스제공 내용형식 · 접근이력 깊이자동화권리 리스크판단
    주의할 점 두 가지. MSCI 공개 PDF 고지문은 그 정보로 데이터베이스나 분석 도구를 만드는 것을 금지합니다. 내부 리서치용 적재는 실무상 흔하지만, SavvyETF 홈페이지처럼 외부에 게시하려면 MSCI 라이선스를 먼저 확인해야 합니다. KRX 정보데이터시스템은 2025년 12월 27일부터 로그인이 필수가 됐고, 2026년 9월 17일 이후 일부 오픈소스 수집기에서 로그인 실패가 보고됐습니다. KRX 경로는 계정 인증 처리를 전제로 설계해야 합니다.

    적재 단계

    P0 · 지금

    시드 이력

    공식 공지·보도 기반 2025-12~2026-09 이벤트 39건, 변경 263행. 출처 등급(공식 PDF / 보도자료 / 언론 / 위키 / 2차)을 행마다 기록.

    P1 · 2–3주

    공지 수집기

    S&P·Nasdaq 보도자료, FTSE Russell 공지, MSCI 공개 PDF, Wikipedia 변경표를 주기적으로 읽어 review_event·constituent_change에 추가.

    P2 · 백필

    스냅샷 diff

    Datastream 과거 구성종목 리스트와 ETF 보유종목(EWY, KODEX 200 등)을 월말·리밸런싱일 기준으로 쌓고, 전후 차이로 공지 누락과 실제 반영일을 검증.

    P3 · 분석

    이벤트 스터디

    발표일·반영일 전후 초과수익과 거래대금, 추정 패시브 수급을 계산해 기존 ETF 리밸런싱 분석과 주보·월보에 연결.

    테이블 구조

    index_master        지수 메타 (사업자, 선정·가중 방식, 주기)
review_event        공지 1건 = 1행
  event_type        regular · adhoc · fast_entry · weight
  cutoff / announce / effective_date
constituent_change  종목 변경 (ADD · DEL · WEIGHT)
  security_name_raw 원문 표기 그대로
  security_id       ISIN / KRX 코드 (매핑 후)
constituent_snapshot 시점별 구성종목·비중
security_map        MSCI 이름 → ISIN 사전

    함께 받는 파일

    • index_changes.csv 통합 변경 이력 263행
    • index_monitor.db 위 스키마로 적재한 SQLite
    • schema.sql 테이블 정의와 스냅샷 diff 쿼리
    • parse_msci_publiclist.py MSCI 공개 PDF 파서(pdfplumber)
    • build_dataset.py 시드 + 파싱 결과 병합·적재

    MSCI 리스트에는 티커가 없어 security_map 매핑이 필요합니다. 한국 5종목은 매핑해 두었습니다.
